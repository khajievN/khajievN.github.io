## Overview

ISOP is a Telegram Mini App that enables users to browse, purchase, and send digital gifts to friends and contacts. Features AI-powered gift recommendations, seamless payment integration, and social sharing — all inside Telegram.

## Key Contributions

- Built Telegram Mini App frontend (React + TypeScript + Vite)
- Developed backend API (NestJS) with Telegram Bot integration
- Built companion React Native mobile app (iOS + Android)
- Created admin dashboard and store dashboard
- Implemented Telegram authentication and payment flows
- Designed landing page and deployment infrastructure (Docker, Nginx, AWS EC2)

## Architecture

- **Mini App Frontend:** React, TypeScript, Vite, Telegram WebApp SDK
- **Backend:** NestJS, PostgreSQL
- **Mobile:** React Native (iOS + Android)
- **Bot:** Telegram Bot API (`@isop_gitft_bot`)
- **Infra:** Docker, Nginx, AWS EC2

`React` `TypeScript` `NestJS` `React Native` `Telegram Bot API` `Docker` `PostgreSQL` `AWS EC2`
