## Overview

Built Conun Bridge at PSJ Global, enabling cross-chain asset transfers between Klaytn and Ethereum networks using centralized servers and ChainLink operators.

## Key Contributions

- Designed and deployed bridge smart contracts
- Built backend services and blockchain event indexers
- Developed ERC-20 token lottery game
- Implemented caching, database schemas, and event indexing
