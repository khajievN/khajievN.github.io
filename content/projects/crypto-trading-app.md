## Overview

Built a full-featured Android crypto trading application at Sixmultiverse, including auto-trading bot algorithms and Ethereum wallet functionality.

## Key Contributions

- Built Android app with MVVM architecture and Jetpack components
- Developed Ethereum wallet features (ERC-20 send/receive)
- Created Redis-based schedulers and Hunterbot auto-trading algorithms
- Optimized database queries and background job performance
- Integrated Jenkins CI/CD pipeline

## Tech Stack

`Kotlin` `Android Jetpack` `Redis` `Spring Boot` `MySQL` `Jenkins` `RxJava`
