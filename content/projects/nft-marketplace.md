## Overview

Developed backend architecture and multi-signature smart contracts for a KYC-compliant NFT marketplace at Paygate, enabling NFT purchases in Korean Won via credit card payments.

## Key Contributions

- Built NFT marketplace APIs (Spring Boot)
- Designed ERC-721/1155 and MultiSig smart contracts
- Integrated KYC authorization and PayGate fiat payment APIs
- Indexed blockchain events and implemented background tasks

## Tech Stack

`Spring Boot` `Solidity` `ERC-721` `ERC-1155` `PostgreSQL` `PayGate API`
